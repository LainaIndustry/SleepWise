# SleepWise - Smart Sleep Calculators

A production-ready static website focused on sleep calculators, sleep education, and sleep wellness.

## Features

- 🔄 Sleep Cycle Calculator
- 😴 Bedtime Calculator
- ⏰ Wake-Up Time Calculator
- 📏 Sleep Duration Calculator
- 📊 Sleep Debt Calculator
- 💤 Nap Calculator
- ✈️ Jet Lag Calculator
- 🏢 Shift Work Planner
- 📔 Sleep Diary with localStorage
- 📈 Sleep Consistency Tracker
- 📚 Sleep Education Articles
- ❓ FAQ Section
- 🌙 Dark/Light Mode
- 📱 Fully Responsive
- ♿ Accessibility First (WCAG 2.2 AA)
- 🚀 Optimized for Core Web Vitals
- 🔍 SEO Friendly with Structured Data
- 📋 PWA Capable
- 🎯 AdSense Ready with Placeholders

## Technology Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router v6
- Lucide React Icons
- Recharts (for data visualization)
- date-fns (for date/time calculations)
- Vitest (for testing)

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/sleepwise.git

# Navigate to project directory
cd sleepwise

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Start development server
npm run dev
